# E-commerce Business Intelligence Platform

An end-to-end business intelligence project for analyzing e-commerce operations using Python, PostgreSQL, SQL, ETL workflows, data modeling, and dashboards.

## Project Goals

- Build a reusable analytics pipeline from raw transactional data
- Clean and transform data using Python
- Store and analyze data in PostgreSQL
- Design a star-schema data model
- Create business KPIs for revenue, customers, products, and operations
- Develop dashboards for decision-making
- Add cloud components such as AWS S3, Redshift, and QuickSight in later stages

## Planned Tech Stack

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI / Tableau / QuickSight
- AWS S3 / Redshift
- Git & GitHub
